# Creator Analytics logo

One stroke writes the C, then spikes up into the A. The spike is the shape of a creator's numbers: flat, then a sharp jump.

## Versions

| Version | Master | Use |
|---|---|---|
| Horizontal | `master/horizontal.svg` | Default |
| Stacked | `master/stacked.svg` | Square and centred spaces |
| Symbol | `master/symbol.svg` | Rail, avatars, 32px and up |
| Small cut | `master/symbol-small.svg` | Below 32px. Heavier, with a more open C |
| Reversed | `master/*-reversed.svg` | White on navy or violet. Slightly thinner so it does not look heavy |
| Wordmark | `master/wordmark.svg` | Only where the symbol already appears nearby |

`variants/` holds one-colour SVGs and PNGs, `web/` the favicon, app icons and `head-snippet.html`, and `board/` the presentation.

## Clear space

Keep two stroke widths clear on every side. The stroke is the thickness of the C. The space scales with the logo.

## Minimum size

| Version | Screen | Print |
|---|---|---|
| Horizontal | 120px wide | 30mm wide |
| Stacked | 80px wide | 20mm wide |
| Symbol | 32px | 8mm |
| Small cut | 16px | 5mm |

## Colour

| Name | HEX | RGB | CMYK (uncalibrated) |
|---|---|---|---|
| Violet | `#6556FB` | 101, 86, 251 | 60, 66, 0, 2 |
| Navy | `#0B1141` | 11, 17, 65 | 83, 74, 0, 75 |
| White | `#FFFFFF` | 255, 255, 255 | 0, 0, 0, 0 |

The CMYK values are direct conversions and this violet is likely to print duller. Proof them, and choose a Pantone from a
physical swatch book before printing.

| Logo | Background | Contrast |
|---|---|---|
| Violet symbol, navy text | White | 4.9:1 symbol, 17.9:1 text |
| White | Violet `#6556FB` | 4.9:1 |
| White | Navy `#0B1141` | 17.9:1 |
| Black | White | 21:1 |

Use the white version on the app's dark surfaces. The violet symbol reaches only 3.7:1 on navy, so keep it to large decorative uses.

## Type

The wordmark is Plus Jakarta Sans Bold, outlined, with slight tightening and a wider word space. The font uses the SIL Open
Font License. Always use the supplied files instead of typing the name.

## Do not

- Stretch, rotate, or redraw the mark.
- Recolour it outside this palette, or add effects, outlines or gradients.
- Rearrange the lockup or change the size of its parts.
- Place it on a busy background without a solid panel behind it.
